## Posting tips

- Post the image first, then the caption as its caption (the link becomes tappable).
- Read each group's rules first; many devotional groups ban ads. Ask the admin if unsure.
- One post per group, not repeated daily. Send from a separate number, a few groups a day.
- In devotional groups, lead with en-1 / hi-1 (the Seetha-Rama image); in matrimony groups, use the parents image.
